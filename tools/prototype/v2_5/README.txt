Python references for the v2.5.x filter work (run with: pip install numpy opencv-python).
  finger.py  skin-coloured blobs touching the page border (HSV hue/saturation, opening, border + size + shape gates)
  filt.py    illumination map + first shadow-severity experiment
  mimic.py   old vs new normalisation (MAGIC / ENHANCE) on page images named page1.png ... (your own warped pages)
The Kotlin in Imaging.kt (shadowStrength, paperLevel, detectFingers, process) is the port of these.
